celist.db — a friendly SQLite database app for the rest of us. (macOS Edition)

-------------------------------------------------
INSTALL
-------------------------------------------------

1. Double-click celist.db.zip to unzip it.
2. Drag celist.db.app into your Applications folder.
3. Open celist.db from Applications.

First launch note:
Because celist.db is distributed as a direct download, macOS
Gatekeeper may show a warning: "cannot verify the developer."
This is normal for unsigned apps. To open it anyway:

   - Right-click (or Control-click) celist.db.app
   - Choose "Open" from the menu
   - Click "Open" in the confirmation dialog

You only need to do this once.

-------------------------------------------------
GETTING STARTED
-------------------------------------------------

On the welcome screen choose "Create Sample Database" to load
a ready-made shop database (customers, orders, products) and
explore. Then:

   Tables   — click a table in the sidebar to browse its data,
              click a cell to edit, use the Home ribbon to add,
              duplicate, or delete records.

   New Table— design a table visually (no SQL needed); we write
              the SQL for you.

   SQL Query— write raw SQL in the built-in editor and see results
              in a grid. Use Cmd+Return to run a query.

-------------------------------------------------
REQUIREMENTS
-------------------------------------------------

   macOS 14 (Sonoma) or later, Apple Silicon or Intel.
